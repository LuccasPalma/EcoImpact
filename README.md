# 🌱 EcoImpact

Aplicativo Android desenvolvido para monitoramento de indicadores de impacto ambiental.

## 📱 Sobre o projeto

O EcoImpact é um aplicativo Android que apresenta informações sobre a qualidade do ar da região do usuário, utilizando dados obtidos através de uma API externa.

O projeto foi desenvolvido como parte dos estudos em desenvolvimento de sistemas, com foco em desenvolvimento mobile e integração com APIs.

## ✨ Funcionalidades

- 🌎 Consulta de qualidade do ar
- 📍 Utilização de localização para identificação da região
- 🌫️ Exibição de níveis de PM2.5 e PM10
- 🟢 Classificação da qualidade do ar
- 🔗 Integração com API de qualidade do ar

## 🛠️ Tecnologias utilizadas

- Kotlin
- Android Studio
- Android SDK
- Gradle
- API Open-Meteo
- Git
- GitHub

## 📡 API
Os dados de qualidade do ar são obtidos através da API de qualidade do ar da Open-Meteo.
